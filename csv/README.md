# CSV Reports

This folder contains CSV outputs from plant leaf disease dataset inspection, cleaning, and leakage analysis.

## Folder structure

- `reports/` — duplicate detection, near-duplicate candidates, split checks, class counts, and image-removal reports.
- `cleaning_reports/` — dataset deduplication manifests and label-conflict reports.
- `dataset_audit/` — image inventory and dataset class-count audit reports.

These files support dataset quality checks, traceability, and reproducibility. They contain metadata and reports, not the complete image dataset.
